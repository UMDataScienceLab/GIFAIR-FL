# GIFAIR-FL
GIFAIR-FL: A Framework for Group and Individual Fairness in Federated Learning

We propose GIFAIR-FL, which adds a regularization term that penalizes the spread in loss across client groups, driving federated learning towards solutions that are fair to both groups and individual clients.
